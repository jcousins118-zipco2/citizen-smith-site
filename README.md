# citizen-smith-site

The published Citizen Smith website: free, plain-English UK rights guidance for debt, housing, energy, telecoms, benefits and employment problems. For members of the public; served by GitHub Pages.

## About
A standalone personal project. It is not part of any other product or platform. The content source is the Citizen-Smith-UK repo; this repo is the published copy.

## State
Live. Published 2026-09-13 (v2). 36 guidance pages across 6 areas.

## Not legal advice
The site gives general information and document support only. Read the disclaimer and sources pages on the site.

## See it locally (3 steps)
1. `git clone` this repo.
2. `python3 -m http.server 8000` in the folder.
3. Open http://localhost:8000.

Plain HTML, CSS and JavaScript. No build step, no package file. Keep `.nojekyll` in place.
Change the guidance in Citizen-Smith-UK first, then publish here. Do not edit pages by hand here.
